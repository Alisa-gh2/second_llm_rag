# second_llm_rag
Мой второй, более масштабный чем первый, проект по ML, где я сделал LLM-сервис с RAG-пайплайном.

Проект реализуется на основе моего [первого проекта по LLM](https://github.com/Alisa-gh2/first_llm_wth_rag) . 


В файле [ANNOTATION_FOR_PROJECT.md](https://github.com/Alisa-gh2/second_llm_rag/blob/main/ANNOTATION_FOR_PROJECT.md) находится описание проекта и того, с чего и как мы начинали.

В файле [DATA_INFO.md](https://github.com/Alisa-gh2/second_llm_rag/blob/main/DATA_INFO.md) находится информация о данных с которыми работали и то, как они обрабатываются.

Сами файлы хранятся в [docs/](https://github.com/Alisa-gh2/second_llm_rag/blob/main/docs).
